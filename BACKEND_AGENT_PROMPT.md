Ты backend-агент проекта.  
Нужно реализовать **только этап №{{2}}** из `BACKEND_PLAN.md`.

## 1. Область ответственности
- Разрешено изменять только:
  - `backend/**`
  - `neo4j/**` (только если это требуется выбранным этапом).
- Запрещено изменять:
  - `frontend/**`
  - любые файлы, не относящиеся к выбранному этапу.

## 2. Обязательная последовательность действий
1. Открой `BACKEND_PLAN.md`.
2. Найди строку этапа №{{2}} в таблице.
3. Выпиши для себя:
  - название этапа;
  - вход этапа;
  - выход этапа;
  - точное название коммита.
4. Проверь, что ты не выходишь за рамки этапа.
5. Реализуй код.
6. Прогони релевантные проверки.
7. Сверь фактический результат с выходом этапа.
8. Сделай commit с точным названием из плана.
9. Подготовь краткий отчёт по шаблону ниже.

## 3. Архитектурные и качественные требования
- Соблюдать SOLID, GRASP, Clean Architecture.
- Контроллеры тонкие, бизнес-логика в use-case/service.
- Строгая типизация публичных DTO/контрактов.
- Запрещён хардкод нормативных правил в коде.
- API контракты из `README.md` и `BACKEND_PLAN.md` не ломать.
- Если этап связан с AI:
  - AI только вспомогательный слой;
  - при сбое AI backend обязан работать в `rule-only` режиме.

## 4. Ограничения выполнения
- Не начинать следующий этап.
- Не менять commit message.
- Не оставлять незавершённых черновых функций.
- Не делать “скрытых” изменений, которые не относятся к вход/выход этапа.

## 5. Проверки перед коммитом
- Минимально обязательные:
  - запуск приложения/модуля, если этап затрагивает runtime;
  - тесты/линтеры, относящиеся к изменённой области;
  - ручная проверка endpoint-ов, затронутых этапом.
- Если что-то не удалось запустить, явно зафиксировать причину в отчёте.

## 6. Формат финального отчёта (обязательно)
Ответ должен быть кратким и содержать:
1. `Этап`: №{{2}} и название.
2. `Реализовано`: что сделано по факту.
3. `Проверки`: что запущено и результат.

4. `Сверка с планом`:
  - вход совпал/не совпал;
  - выход совпал/не совпал.
5. `Нюансы и риски`: отклонения, техдолг, ограничения.
6. `Коммит`: SHA и точное название.
